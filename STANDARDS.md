# STANDARDS.md — Review & Deployment Standards for CompressZ

This document specifies the technical standards, toolchain invariants, and deployment constraints for CompressZ. All contributors and automated agents must adhere to these specifications before creating pull requests or pushing releases.

---

## 1. Toolchain Isolation & Manifest Purity

1. **Canonical npm Environment**:
   - `package.json` and `package-lock.json` are the sole canonical manifestations for GitHub Actions CI and Cloudflare Pages.
   - Zero mentions of `deno` are permitted inside `package.json` scripts or dependencies (enforced by `tests/hallmark.test.ts`).
   - `.gitignore` must strictly isolate local developer tooling (`deno.json`, `deno.lock`, `.deno/`).
2. **Runtime Engine Versions**:
   - Pinned `.node-version` (`22.14.0`) and `.nvmrc` (`22.14.0`) are required for Cloudflare Pages build compatibility.
   - Node engine constraint: `^20.19.0 || ^22.13.0 || >=24`.

---

## 2. Cloudflare Pages Asset Ceilings

1. **Hard File Size Cap (25 MiB)**:
   - Cloudflare Pages strictly rejects any deployed asset file exceeding 25 MiB.
   - Build script `scripts/strip-oversized-assets.mjs` enforces a 24 MiB threshold (`THRESHOLD = 24 * 1024 * 1024`), pruning large asyncify WASM binaries generated by unneeded dependencies.
   - `npm run build` must be verified to ensure `dist/assets` contains zero files $\ge 24\text{ MiB}$.

---

## 3. Architectural & Anti-Slop Floor Rules

1. **Four Design Disciplines**:
   - `design-taste-frontend`: Dense, compact, tool-first layouts. Verb + noun actions ("Download All", "Compress Images", "Extract Markdown"). No unneeded saturated purple/lavender in utility workspaces.
   - `frontend-design`: Zero AI tells (no glued arrows, no pastel gradients, no single-word colored accent gimmicks).
   - `hallmark`: The CSS floor:
     - `overflow-x: clip` on `html` and `body`.
     - High-contrast `:focus-visible` styling on all interactive controls.
     - Zero `transition: all` rules (transitions must specify explicit property names).
     - Full `prefers-reduced-motion` compliance.
     - Resilient typography (minimum 12px / `text-xs` font size).
   - `impeccable`: Scannable tabular density, clear state transitions (`idle`, `compressing`, `complete`, `error`), and graceful error recovery.
2. **Dependency Hygiene**:
   - React, `@types/react`, and `animejs` are completely forbidden (enforced by `tests/hallmark.test.ts`).
   - Svelte 5 with runes (`$state`, `$derived`, `$props`) is the standard UI framework.
   - Native Web Animations API (`src/lib/motion.ts`) powers fluid spring animations with zero external dependencies.

---

## 4. Pre-Upload Manual Re-Review Checklist

- [ ] Run test suite with multiple workers: `deno test --parallel --allow-read tests/` (100% pass rate).
- [ ] Typecheck all engine modules: `deno check tests/*.ts src/lib/*.ts`.
- [ ] Verify Hallmark test: `deno test --allow-read tests/hallmark.test.ts`.
- [ ] Verify build asset sizes are under 24 MiB.
- [ ] Confirm no user file bytes are sent to any external server.
- [ ] For changes touching Safari/WebKit, verify `docs/SAFARI_DEVICE_CHECKLIST.md`.
